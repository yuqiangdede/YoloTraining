# 标注框类别标签显示

## 目标

人工标注画布中的检测框只显示可读的类别名称，并使用更紧凑的字号。

## 范围

- 仅修改前端 `AnnotationCanvas` 的矩形/OBB 标签渲染与相关样式。
- 将当前的“内部类别 ID + 类别名称”改为仅显示类别名称。
- 找不到类别时显示“未分类”，避免将内部 UUID 显示给用户。
- 缩小标签字号及其背景高度，保持框的颜色和编辑行为不变。

## 非目标

- 不修改已有标注数据中的 `labelId`。
- 不修改类别管理、API、数据集导出或训练流程。

## 验证

- 更新组件测试，断言画布显示类别名称且不显示类别 ID。
- 运行前端测试与生产构建。
