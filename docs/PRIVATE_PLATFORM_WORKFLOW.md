# 私有视觉平台工作流

## 1. 产品定位

视觉模型训练台是单机、私有化、项目内闭环的视觉数据与模型工作台。数据、模型、数据库、虚拟环境、日志和运行产物均保存在仓库目录，不依赖 CVAT、Roboflow、FiftyOne 或 X-AnyLabeling 服务。

外部项目只用于参考成熟工作流：

| 参考项目 | 采用的设计 | 本平台实现边界 |
| --- | --- | --- |
| [ModelCub](https://github.com/SeifBoukerdenna/ModelCub) | 项目、数据集、训练和模型的一体化本地路径 | 保留 FastAPI + SQLite + 文件系统，不引入其运行时 |
| [CVAT](https://github.com/cvat-ai/cvat) | 标注任务、负责人、素材范围、进度、图片/视频入口 | 不建设审核阶段；任务完成即可冻结版本 |
| [X-AnyLabeling](https://github.com/CVHub520/X-AnyLabeling) | 多形状标注、视频抽帧、YOLO/SAM 智能标注 | 智能标注在服务端本地运行，不依赖桌面客户端 |
| [FiftyOne](https://github.com/voxel51/fiftyone) | 数据质量、逐样本 TP/FP/FN、错误样本优先排序 | 不引入 FiftyOne/MongoDB；结果写入本地 SQLite |

## 2. 资源层级

```text
项目 Project
├─ 数据集 Dataset
│  ├─ 图片素材 Asset
│  ├─ 视频原件 -> 抽帧图片 Asset
│  ├─ 人工标注 Annotation
│  ├─ 标注任务 AnnotationTask
│  └─ 不可变版本 DatasetVersion
│     └─ 训练任务 TrainingJob
│        └─ 模型产物 ModelArtifact
└─ 错误分析 AnalysisJob
```

- 项目是顶层业务容器。
- 数据集固定任务类型和类别，素材与标注属于数据集。
- 数据集版本是可复现训练输入，记录父版本、来源、内容哈希和随机划分。
- 训练任务引用具体数据集版本；模型通过训练任务回溯到数据集和项目。
- 旧数据会自动归入“默认项目”，无需手工迁移。

## 3. 类 Roboflow 操作路径

### 3.1 创建项目和数据集

1. 打开“项目”，填写项目名称和用途说明。
2. 进入项目工作台，点击“新建数据集”。
3. 选择目标检测、实例分割、语义分割、姿态估计或旋转框检测。
4. 配置类别；姿态数据集额外填写关键点数量。

### 3.2 导入图片或视频

- 图片：点击“导入图片”，可一次选择多张。服务端使用 Pillow 解码校验，以 SHA-256 跳过内容重复文件。
- 视频：先设置“抽帧间隔”，再点击“视频抽帧”。原视频保存到 `uploads/videos/<数据集ID>`，抽帧图片保存到 `uploads/assets/<数据集ID>`，并带有来源视频和帧号标签。
- 单个视频上限为 2 GB；抽帧间隔为 1–10000。

### 3.3 自动标注与任务分发

1. 在“预标注设置”选择 YOLO、YOLO + SAM 或 SAM，配置置信度。
2. 点击“开始预标注并保存配置”，任务进入本地队列。
3. 在“标注任务分发”填写任务名和负责人；当前版本默认把全部未删除素材纳入任务。
4. 任务无审核阶段，进度按已完成素材自动计算。

### 3.4 人工标注

| 数据集任务 | 标注形状 |
| --- | --- |
| 目标检测 | 矩形框 |
| 实例分割 | 多边形 |
| 语义分割 | 多边形或像素掩码 |
| 姿态估计 | 关键点与可见性 |
| 旋转框检测 | OBB 旋转框 |

`Ctrl+S` 保存草稿。“完成”表示可进入版本冻结，不要求额外审核。

### 3.5 冻结训练版本

1. 至少准备 2 张素材，并完成全部标注。
2. 运行数据质量检查；存在阻断问题时先修复。
3. 填写版本名并冻结。冻结后素材、标注、类别、训练/验证/测试划分和内容哈希不再改变。

### 3.6 本地 GPU 训练

1. 把匹配任务的权重放入 `models/pretrained`。
2. 打开“训练任务”，选择数据集版本、模型、图像尺寸、批量和 epoch。
3. Worker 串行领取 GPU 任务；页面显示排队位置、epoch、进度、日志和错误详情。
4. 暂停在当前 epoch 保存 checkpoint 后生效；恢复使用 `last.pt`。
5. 成功后在“模型结果”查看 `best.pt`、`last.pt`、训练证据和 ONNX 导出。

### 3.7 错误样本分析

1. 在数据集工作台打开“错误分析”。
2. 选择与数据集任务一致的训练模型或官方预训练模型。
3. 设置推理置信度和 IoU 阈值，开始分析。
4. 分析任务进入同一条本地队列，支持进度和取消。
5. 完成后查看 TP、FP、FN 总数；错误样本按 `FP + FN` 从高到低排列。
6. 点击“打开标注”直接回到对应素材修正标注。

## 4. 私有化部署

### 4.1 默认单机模式

```powershell
Set-Location E:\Code\PyCode\ultralytics
.\scripts\start.ps1
```

访问 `http://127.0.0.1:8000`。默认只监听回环地址，不暴露到局域网，不提供账号系统。

```powershell
.\scripts\stop.ps1
.\scripts\diagnose.ps1
```

### 4.2 目录与迁移

复制整个项目目录即可迁移，必须同时保留：

- `.venv`：项目内 Python 环境；跨机器时建议重新执行安装脚本。
- `data/studio.db`：项目、数据集、任务和模型元数据。
- `uploads`：图片、视频和掩码。
- `models`：预训练与归档权重。
- `runs`：训练、导出、预标注、视频推理结果。
- `backups`、`logs`、`resources`。

数据库只保存项目相对路径。跨机器复制后先运行诊断，再启动服务。

### 4.3 局域网边界

当前默认模式是可信单机环境。若要绑定局域网地址，必须先补充反向代理、TLS、登录鉴权、权限控制、上传限流和备份策略；不要直接把无账号的 FastAPI 服务暴露到公网。

## 6. 当前边界

- 负责人是任务元数据文本，不是账号或权限主体。
- 标注任务当前按显式素材 ID 或全部素材分发，不提供多人实时协同编辑。
- 模型错误分析使用预测框与标注外接框做 IoU 匹配；分割、姿态和 OBB 的精细任务指标仍应以训练/验证阶段官方指标为准。
- Worker 为单机串行队列，不是分布式调度器。
- 外部参考项目不是运行依赖，也没有双向同步。
